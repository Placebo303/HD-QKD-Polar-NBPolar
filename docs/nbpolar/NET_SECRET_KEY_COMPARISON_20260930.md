- N = 32768 符号/块；q = 1024（每符号 10 bit）；块间独立。
- **H(A) = 10 bit/符号为假设**（Alice 符号在 q=1024 上均匀）。文件中没有实测 H(A) bit 值：
  `workspace/r2c_strong_binary_msd_shg_64/results.json` 的 `per_session_construction.<G>.invariance` 只有相对均匀性检验——

  H(A) 假设**同时影响绝对水平与方案间 Δr_pool**（见 §3，Δr 含 `H(A)−χ`）。
- H(A|B) = H_total，每会话各自取：G2 = 0.8168138204133305，G3 = 0.8214782076249098；I(A;B) = H(A) − H(A|B)
  （G2 9.1832，G3 9.1785，pooled 9.1809）。pooled 用 n 加权均值（G2/G3 各 32 块）。
- 记号：p̂ = 块失败率；f_book = 每块披露 / (N·H(A|B))，含各方案的 CRC/tag 口径（见 §2）；
  d = f_book·H(A|B) = 每原始符号披露（bit）。

### 1.1 净密钥公式（M1，主指标：每原始符号）

- 成功块产出 `H(A) − χ − f_book·H(A|B)`，失败块产出 0，块间独立，**失败块的披露不扣其他块**：
  `r_pool(χ) = (1 − p̂)·(H(A) − χ − f_book·H(A|B))`，单位 bit/原始符号。
- 每成功符号（辅助，**不作比较主证据**）：`r_succ(χ) = H(A) − χ − f_book·H(A|B)`；`r_pool = (1−p̂)·r_succ`。
- 盈亏平衡：`χ* = H(A) − f_book·H(A|B)`（r_pool = r_succ = 0 的 χ；与 p̂ 无关）。
- Wilson 95%（z = 1.96）。R2C F3 的 0/64 用 Wilson 上界 0.0566，不用 p̂ = 0 充当保证。

## 3. Δr_pool 推导（M2；替换 v1 “χ 抵消”结论）

同一口径下两方案 A、B（失败率 p̂_A、p̂_B，披露 d_A = f_A·H，d_B = f_B·H，c = H(A) − χ）：

`r_pool,A − r_pool,B = (1−p̂_A)(c − d_A) − (1−p̂_B)(c − d_B)`
`= [(1−p̂_A) − (1−p̂_B)]·c − [(1−p̂_A)d_A − (1−p̂_B)d_B]`

即

**`Δr_pool = (p̂_B − p̂_A)·(H(A) − χ) − [(1−p̂_A)·f_A − (1−p̂_B)·f_B]·H(A|B)`**（脚本逐点断言与直接相减一致，误差 <1e-12）。

- 第一项（失败率差 × (H(A)−χ)）**依赖 χ 与 H(A)**，一般是主导项：p̂ 差 0.03 就带来约 0.3 bit/符号（χ=0），
  而第二项（f 差 ×H(A|B)）通常只有 0.05–0.1 bit。
- 因此**排序依赖 χ 与 H(A)，不能称“χ 无关”**。χ 只在“每成功符号”口径（`r_succ` 之差 = −(f_A−f_B)·H，不含 p̂）抵消，
  但那不是净密钥产出比较的主口径（它把失败块的零产出忽略了）。
- 例（R2 − F3，pooled，χ = 0）：`(0 − 0.03125)×10 = −0.3125`；披露项 `+0.0664`（d_R2 = 1.0417，d_F3 = 1.0755）；
  合计 −0.246，与 §6 表一致。χ 增大时第一项按 (H(A)−χ) 缩小，符号可翻转（此例在 χ≈8 附近翻正）。

### 3.1 不确定性传播（M3）

`r_pool` 对 p̂ 线性，所以 Δr_pool 的保守区间取 p̂_A、p̂_B 各自 Wilson 95% 端点的四个角点的最小/最大。
当 χ ≤ 两方案 χ* 时，下界 = A 取 p 上界、B 取 p 下界，上界反之（脚本断言等于角点极值）。
A、B 视为独立传播（保守）；区间跨 0 即“不可区分”。f 取点值（f_book 是构造设定量，不带抽样区间）。
pooled 用 `(1−p̄)(H(A)−χ−d̄)`，d̄ 为 n 加权披露；与逐会话精确加权的差：NB/R2C 方案 0，基线最大 0.0025。

## 7. 结论（M6；如实按可区分性）

1. **f≈1.24（R2E）vs f≈1.27（R2）：不可区分**（G2、G3、pooled，χ = 0..8 全部区间跨 0）。
   点估计的符号还随 χ 变化（pooled：χ≤7 时 R2 略优、χ=8 时 R2E 略优），且 2/64 与 3/64 的失败数差异远在抽样噪声内。
   不得据此宣称任何一点“更划算”。
2. **NB vs 二元：分点、分会话。**
   - 同披露点（R2 vs F2）：G2 不可区分；G3 与 pooled 在所有 χ 下 R2 显著更优（G3 F2 失败 16/32，
     pooled 显著性由 G3 驱动）。G3 的 F2 点有构造失配（设计 Σp̃ G3 = 0.63 vs G2 = 0.074，R2C 合同与 RESULT_SUMMARY 已载明），
     所以该结论**仅限同披露 F2 点，不得泛化为“NB 优于二元理论最优”**。
   - 自洽点（R2 vs F3）：G2、G3、pooled 全部不可区分。F3 点估计在低 χ 略占优（pooled χ=0 时 −0.246，主要来自 0/64 对 2/64 的失败率差×(H(A)−χ)），
     但区间 [−0.92,+0.46] 远大于点估计；该差随 χ 增大而收窄。二元以更高 f（1.31 vs 1.27）与 NB 统计不可区分。
3. **R2B（不可用点）**：点估计一律 R2 更优；仅 pooled 在 χ ≤ 7 下区间不含 0，逐会话不可区分。
   这只是“R2B 无优势”的记录，不改变其“不可用”定性。
4. **对 f 的论文叙述**：f 是论文主指标；β 对 f 不敏感（§5）；净密钥比较受 64 块小样本限制，失败率差 ×(H(A)−χ) 是主导项，
   因此区间宽（χ=0 时半宽约 1 bit/符号）。没有“排序稳健”或“与 χ 无关”的结论。

## 9. 不确定性与局限

- 64 块样本小：0/64 与 2/64 不可区分（F3 pooled Wilson 上界 0.0566 vs R2 pooled p̂ 0.031，前者在后者 CI 内）。
- **绝对水平（r ≈ 8.7、χ* ≈ 8.96）由 H(A)=10 假设与 χ 参数化决定：χ 无实测，H(A) 无实测 bit 值；
  真实 χ 需安全分析（例如相位基/Franson 可见度给出 Eve 信息上界），项目目前没有该数，故绝对 r 不可作结论。**
  若 χ 接近 I(A;B) ≈ 9.18，所有方案净密钥都接近或低于零。
- 二元未做 CRC/软前缀/更大 L（R2C 为 SCL L=16 min-sum 无 CRC，合同已载明不得宣称二元最优）；
  二元与 NB 的 FER 点不同（F3 f≈1.31 vs NB f≈1.27）。
- R2C 设计帧不含真实尾部（合成设计帧，CAL32 拟合模型生成）。
- G2 块参与过 R2D 选点（`selection_freedom_exercised`）；分层（A1_CAL/EVAL/HELDOUT）见各 `results.json`，本文未重复分层。
- 失败块的披露不扣其他块（PI 冻结口径，M1）：若安全证明要求失败块的泄漏也计入总泄漏，则实际净密钥更低，本文未处理。
- undetected 各方案均为 0，单列，未并入 p̂。
