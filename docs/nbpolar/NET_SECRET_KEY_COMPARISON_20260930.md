### 1.1 净密钥公式

- 每符号泄漏 = `f_eff · H(A|B)`（f_eff 已含“失败块披露照付、不产出密钥”的整块损失：`f_eff = f_book/(1−p̂)`）。
- 每成功符号净密钥：`r(χ) = H(A) − χ − f_eff·H(A|B)`，χ = Eve 每符号 Holevo 信息量。
- 盈亏平衡：`χ* = H(A) − f_eff·H(A|B)`（net = 0 时的 χ）。
- 每池符号净密钥（含失败块零产出）：`(1−p̂)·(H(A) − χ) − f_book·H(A|B)`。
- 等价关系：**每池口径 = (1−p̂) × 每成功符号口径**（`r_pool(χ) = (1−p̂)·r(χ)`），两种口径都给。
- Wilson 95%（z = 1.96），每会话与 pooled 都给；`f_eff_upper = f_book/(1 − p_upper)`。
  R2C F3 的 0/64 用 Wilson 上界 0.0566 算 `f_eff_upper`，不用 p̂=0。

## 3. Δr 的 χ 无关性（本分析稳健性的核心）

比较同一会话（或同一 pooled 口径）下两个方案 A、B 的每成功符号净密钥：

`r_A(χ) − r_B(χ) = [H(A) − χ − f_eff,A·H] − [H(A) − χ − f_eff,B·H] = −(f_eff,A − f_eff,B)·H(A|B)`。

即 **Δr = −(f_eff,A − f_eff,B)·H(A|B)，χ 项抵消**。推论：

1. **方案间优劣与 Eve 信息量假设 χ 无关**——χ 只决定绝对水平 r 与盈亏平衡点 χ*，不改变“谁更划算”。
2. Δr 中也不出现 H(A)——**H(A)=10 的均匀性假设不影响任何方案间比较结论**，只影响绝对水平。
3. 因此 §5 的 Δr 表是回答“谁更划算”的主证据；§4 主表的 χ 网格只用于定位绝对水平与盈亏平衡。
