# Design

Tier X writes only under `workspace/probes/<id>/`, begins with a three-line
preregistration (question, parameters, command), and ends with one result
record. It may run multiple synthetic seeds/models and use focused review, but
creates no candidate/accepted token, changes no scientific status, and cannot
retroactively strengthen accepted evidence.

Tier Y retains explicit authorization, frozen thresholds, one-shot attempt,
Pre-EXECUTE, Pre-RESULT and main-thread acceptance. A claim-bearing synthetic
threshold requires prior Tier-X variance/sensitivity evidence or an explicit
statement that one draw cannot discriminate the hypothesis.

For a same-point semantic delta, reuse unchanged predecessor contracts and use
one delta document, one independent freeze review, one execution and one
Pre-RESULT review. Batch index/decision-log/memory updates at milestones.
